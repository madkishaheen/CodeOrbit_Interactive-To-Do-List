# Task 3 — Interactive To-Do List

**Internship:** CodeOrbit Tech — Frontend Development

## Overview
An interactive task manager that lets users add tasks, mark them as completed, delete tasks, and filter the task list.

## Features
- Add new tasks
- Mark tasks as completed or incomplete
- Delete individual tasks
- Filter tasks by all, active, or completed
- Clear completed tasks
- Show task counts and progress
- Save tasks in browser `localStorage` so they remain after a page refresh

## Files
```text
Task3-To-Do-List/
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run
1. Open the `Task3-To-Do-List` folder in Visual Studio Code.
2. Make sure `index.html`, `style.css`, and `script.js` are in the same folder.
3. Right-click `index.html` and select **Open with Live Server**.
4. If Live Server is unavailable, open `index.html` directly in a web browser.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser `localStorage`

## Learning Outcomes
Practiced DOM manipulation, event handling, list rendering, filtering, and browser storage.

## Data Note
Tasks are saved in the browser on the device/profile where the app is used. They are not automatically synced across devices.
